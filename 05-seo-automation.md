# 5. SEO Automation

**RNF Technologies · April–May 2026 · AI agents for SEO work: a working first agent and a proposal**

## The problem
The account-management team did every SEO task by hand for each client: meta tags, keyword research, schema, content briefs and monthly reports. One page's meta title and description took about 30 minutes, quality depended on who did the work, and some tasks were skipped for lack of time.

## What I built
- **A map of the SEO process,** and a plan for a team of 10 AI agents built on Claude Code, one for each SEO task.
- **The first agent, Meta Writer.** It reads a client's web page through a small Python scraper, then writes SEO titles and descriptions, with a report of what to fix.
- **A proposal for seniors,** with the problem, the plan by phase and the expected gain.

## The test
I ran Meta Writer on a real client's website. It found that the homepage title was only 29 characters and was missing the client's main keyword, a gap that is easy to fix.

## Where it stands
As of May 2026, one agent was built and tested, nine more were planned, and the proposal was waiting for approval from seniors.

## My part
I mapped the process, wrote the proposal and built the first agent with Claude Code.

## Tools
Claude Code · Python · Firecrawl (web scraping)

## What I learned
Start with one agent on one real client. A real result is the best argument for the bigger plan.
