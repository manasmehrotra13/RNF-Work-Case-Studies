I'm Manas Mehrotra, a Data Analyst at **RNF Technologies** in Noida, India (since June 2025). I work in the digital marketing division, in a small data team that supports the lead-generation, sales and project-management teams.

**Right now** I run and improve The Scale Agency Dashboard and the contest boards.

These pages describe what I built and how it works. **They have no company code, no client or colleague names and no money figures**, because that work belongs to the company. A few pages have screenshots that I have already shared publicly, with the client's name changed.

## How I work

I design the data side: the data model, how each number is calculated, the business rules, and the checks that prove the numbers are right. I write the logic out in detail and build the tools with an AI coding assistant (Claude), then I test every number before anything goes live.

## Smaller work

- **HubSpot backup:** a workflow in n8n that copies new HubSpot records into our database every 5 minutes, with an alert if a run is missed.
- **Mailbox sorting:** a Google Apps Script that sorts a shared mailbox into out-of-office replies, junk, real leads, promotions and failed deliveries.
- **Lead-generation report:** a live report of leads, duplicates and rejected leads for each lead-generation team.
- **HubSpot data extraction:** scripts that pull HubSpot data into sheets for quick reports.
- **Data enrichment:** a Google Apps Script that uses a company data API (country, state, industry, year founded, size) to fill in lead details, so sales reps know the company before the call.
- **Conference lead assignment:** the same lead assignment idea for the conference team. Leads go from a sheet to the right sales rep in HubSpot, and the rep gets an email.
- **HubSpot chat setup:** researched how to add a HubSpot chatflow to the company website, so a visitor's message reaches a sales rep. The development team then added it.
- **NAL Verification Status monitor:** a Python script that watches one HubSpot property and posts a Google Chat alert when anyone other than the approved editors changes it.
- **Employee list sync:** pulls the HubSpot users list through the API into a live sheet, in place of a manual export.
- **Mailbox backup:** a Google Apps Script that copies a client's order mailbox into a Google Sheet every 2 hours.
- **Performance reports:** Excel and PDF reports on project-manager and sales performance, for the managers.
